What it does

Everything you'd want from
a server management bot.

Built for server admins who care about their communities. Every feature works out of the box with sensible defaults.

Moderation Suite

Full moderation toolkit with warn, kick, ban, mute, and timed actions. Moderation cases with notes, tags, and exportable history. Watchlists for keeping an eye on members.

/warn /kick /ban /mute /purge /modlog /watchlist
screenshot: moderation case view

Auto-Moderation

Configurable spam and raid detection with automatic responses. Flagged events dashboard for reviewing automated actions. Fine-tune thresholds per guild.

spam detection raid protection flagged events configurable thresholds

AI Assistant

Claude-powered conversational AI with tool use. The assistant can look up server info, check moderation cases, and answer questions with context about your server.

Anthropic Claude tool calling cost tracking rate limiting
screenshot: AI assistant interaction

Audio & Soundboard

Play custom sound clips in voice channels. Upload and manage sounds per guild. Web-based soundboard portal lets members trigger sounds from their browser.

/play /sounds web portal FFmpeg

Text-to-Speech & VOX

Azure-powered TTS with SSML support, voice selection, and style presets. Plus a Half-Life inspired VOX system that concatenates clip libraries for retro announcements.

/tts /vox /fvox SSML editor Azure Speech
screenshot: TTS portal with voice selector

Analytics & Metrics

Engagement analytics, moderation stats, command performance tracking, and real-time health monitoring. Historical metrics with hourly and daily aggregation.

engagement performance real-time SignalR

Scheduling & Reminders

Cron-based scheduled messages for recurring announcements. Personal reminders with natural language time parsing. Manage everything from Discord or the web dashboard.

/schedule-create /remind set cron expressions natural language

Welcome System

Customizable welcome messages for new members. Configure per-channel, set custom messages with variables, and test before going live.

/welcome custom messages per-channel

Web Dashboard

Full-featured admin dashboard with guild management, member directories, log browsers, and settings. Member portals let users interact with audio features from their browser.

Razor Pages Discord OAuth role-based access real-time updates
screenshot: admin dashboard overview

Under the hood

Built on solid foundations.

Production-grade infrastructure with enterprise patterns. Not over-engineered — just well-engineered.

Framework .NET 9 Latest LTS runtime with AOT-ready architecture
Discord Discord.NET Slash commands, interactions, voice, and gateway events
Data Entity Framework Core Code-first with dual provider support
Database SQLite & PostgreSQL Start with SQLite, scale to Postgres when ready
AI Anthropic Claude Agentic assistant with tool use and cost tracking
Voice Azure Speech Services Neural TTS with SSML and multiple voices
Frontend Razor Pages + Tailwind Server-rendered UI with HTMX and Alpine.js
Real-time SignalR Live metrics, notifications, and playback status
Logging Serilog + Seq Structured logging with centralized search
Tracing OpenTelemetry Distributed tracing with Elastic APM
Audio FFmpeg + libopus Audio transcoding and Opus encoding for Discord
Deploy Docker Containerized with multi-stage builds

Discord Developer Portal app

# Clone and run
git clone https://github.com/your/repo
cd discordbot

# Set your Discord token
dotnet user-secrets set "Discord:Token" "your-token"

# Run it
dotnet run --project src/DiscordBot.Bot
